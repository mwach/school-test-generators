Proporczyk klasowy ma kształt trójkąta równobocznego o boku a = 5/6 m. Brzeg proporczyka trzeba obszyć taśmą, a całą powierzchnię wyciąć z materiału.

b) Jakiej powierzchni materiału potrzeba? Wynik podaj w postaci ułamka z pierwiastkiem oraz w przybliżeniu do 0,01 m² (przyjmij √3 ≈ 1,73).

Klucz odpowiedzi

Trójkąt równoboczny — obwód, pole, wysokość (poziom rozszerzony)

Wzory, które warto znać

Obwód: L = 3a Wysokość: h = (a·√3) / 2 Pole: P = (a²·√3) / 4
gdzie a oznacza długość boku trójkąta.
Przypomnienie przed rozwiązywaniem: √a · √b = √(a·b)  ·  wyłączanie czynnika przed pierwiastek, np. √48 = √(16·3) = 4√3  ·  (p/q)² = p²/q²  ·  ułamek mnożymy przez liczbę, mnożąc licznik (mianownik zostaje bez zmian), np. (3/4)·2 = 6/4 = 3/2.
Zadanie 1. a = √48 = √(16·3) = 4√3 cm. L = 3a = 3 · 4√3 = 12√3 cm (≈ 20,78 cm).
Zadanie 2. a = L / 3 = 15√2 / 3 = 5√2 cm (≈ 7,07 cm).
Zadanie 3. h = (a·√3)/2 = (2√6 · √3)/2 = 2√18 / 2 = √18 = √(9·2) = 3√2 cm (≈ 4,24 cm).
Zadanie 4. P = (a²·√3)/4 = ((3/4)²·√3)/4 = (9/16 · √3)/4 = 9√3/64 dm² (≈ 0,24 dm²).
Zadanie 5. h = (a·√3)/2 ⟹ a = 2h/√3 = 2·(3√3/4) / √3 = (6√3/4)/√3 = 6/4 = 3/2 cm (1,5 cm). L = 3a = 3 · 3/2 = 9/2 cm (4,5 cm).
Zadanie 6. a) L = 3a = 3 · 5/6 = 15/6 = 5/2 m (2,5 m) taśmy. b) P = (a²·√3)/4 = ((5/6)²·√3)/4 = (25/36 · √3)/4 = 25√3/144 m² ≈ 25 · 1,73 / 144 ≈ 0,30 m².
