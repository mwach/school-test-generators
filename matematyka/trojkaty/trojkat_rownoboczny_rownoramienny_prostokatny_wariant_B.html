Klucz odpowiedzi

Trójkąt równoboczny i równoramienny prostokątny — obwód, pole, wysokość (wariant B, poziom rozszerzony)

Wzory, które warto znać

Trójkąt równoboczny (bok a)
Obwód: L = 3a Wysokość: h = (a·√3) / 2 Pole: P = (a²·√3) / 4
Trójkąt równoramienny prostokątny (przyprostokątna a, przeciwprostokątna c)
Przeciwprostokątna: c = a√2 Obwód: L = 2a + a√2 Pole: P = a² / 2
Połówka trójkąta równobocznego (przyprostokątne a/2 i h, przeciwprostokątna a)
Pole: P = (a²·√3) / 8 Obwód: L = a·(3+√3) / 2 gdzie: h = (a·√3) / 2
gdzie a oznacza długość boku (w trójkącie prostokątnym — przyprostokątnej).
Przypomnienie przed rozwiązywaniem: √a · √b = √(a·b), w szczególności √a · √a = a  ·  wyłączanie czynnika przed pierwiastek, np. √108 = √(36·3) = 6√3  ·  (k√m)² = k²·m  ·  (p/q)² = p²/q²  ·  ułamek mnożymy przez liczbę, mnożąc licznik (mianownik zostaje bez zmian).
Zadanie 1. a = √108 = √(36·3) = 6√3 cm. L = 3a = 3 · 6√3 = 18√3 cm (≈ 31,18 cm).
Zadanie 2. h = (a·√3)/2 ⟹ a = 2h/√3 = 2 · 5√3 / √3 = 10√3/√3 = 10 cm. L = 3a = 3 · 10 = 30 cm.
Zadanie 3. P = (a²·√3)/4 = ((3/5)²·√3)/4 = (9/25 · √3)/4 = 9√3/100 m² (≈ 0,16 m²).
Zadanie 4. c = a√2 = 5√2 · √2 = 5 · 2 = 10 cm.
Zadanie 5. a = √50 = √(25·2) = 5√2 cm. P = a²/2 = (5√2)²/2 = (25·2)/2 = 50/2 = 25 cm².
Zadanie 6. a) L = 2a + a√2 = a(2+√2) = 3√2 · (2+√2) = 6√2 + 3·2 = 6√2 + 6 = (6√2 + 6) m ≈ 6·1,41 + 6 ≈ 14,46 m lamówki. b) P = a²/2 = (3√2)²/2 = (9·2)/2 = 18/2 = 9 m² materiału.
Zadanie 7. Przeciwprostokątna = a = 2√3 cm. Krótsza przyprostokątna = a/2 = √3 cm. Dłuższa przyprostokątna (wysokość trójkąta równobocznego) = h = (a·√3)/2 = (2√3 · √3)/2 = (2·3)/2 = 3 cm. P = (1/2)·(a/2)·h = (1/2)·√3·3 = 3√3/2 cm² (≈ 2,60 cm²). L = a/2 + h + a = √3 + 3 + 2√3 = 3 + 3√3 = 3(√3+1) cm (≈ 8,20 cm).
Zadanie 8. h = (a·√3)/2 ⟹ a = 2h/√3 = 2 · 3√3/√3 = 6√3/√3 = 6 cm (przeciwprostokątna = bok trójkąta równobocznego). Krótsza przyprostokątna = a/2 = 3 cm. P = (1/2)·(a/2)·h = (1/2)·3·3√3 = 9√3/2 cm² (≈ 7,79 cm²). L = a/2 + h + a = 3 + 3√3 + 6 = 9 + 3√3 = 3(3+√3) cm (≈ 14,20 cm).
