Trójkąt równoboczny i równoramienny prostokątny — obwód, pole, wysokość (wariant C, poziom rozszerzony)

Wzory, które warto znać

Trójkąt równoboczny (bok a)
Obwód: L = 3a Wysokość: h = (a·√3) / 2 Pole: P = (a²·√3) / 4
Trójkąt równoramienny prostokątny (przyprostokątna a, przeciwprostokątna c)
Przeciwprostokątna: c = a√2 Obwód: L = 2a + a√2 Pole: P = a² / 2
Połówka trójkąta równobocznego (przyprostokątne a/2 i h, przeciwprostokątna a)
Pole: P = (a²·√3) / 8 Obwód: L = a·(3+√3) / 2 gdzie: h = (a·√3) / 2
gdzie a oznacza długość boku (w trójkącie prostokątnym — przyprostokątnej).
Przypomnienie przed rozwiązywaniem: √a · √b = √(a·b), w szczególności √a · √a = a  ·  wyłączanie czynnika przed pierwiastek, np. √75 = √(25·3) = 5√3  ·  (k√m)² = k²·m  ·  (p/q)² = p²/q²  ·  ułamek mnożymy przez liczbę, mnożąc licznik (mianownik zostaje bez zmian).
Zadanie 1. a = √75 = √(25·3) = 5√3 cm. L = 3a = 3 · 5√3 = 15√3 cm (≈ 25,95 cm).
Zadanie 2. h = (a·√3)/2 ⟹ a = 2h/√3 = 2 · 7√3 / √3 = 14√3/√3 = 14 cm. L = 3a = 3 · 14 = 42 cm.
Zadanie 3. P = (a²·√3)/4 = ((2/3)²·√3)/4 = (4/9 · √3)/4 = √3/9 m² (≈ 0,19 m²).
Zadanie 4. c = a√2 = 7√2 · √2 = 7 · 2 = 14 cm.
Zadanie 5. a = √72 = √(36·2) = 6√2 cm. P = a²/2 = (6√2)²/2 = (36·2)/2 = 72/2 = 36 cm².
Zadanie 6. a) L = 2a + a√2 = a(2+√2) = 4√2 · (2+√2) = 8√2 + 4·2 = 8√2 + 8 = (8√2 + 8) m ≈ 8·1,41 + 8 ≈ 19,28 m obrzeża. b) P = a²/2 = (4√2)²/2 = (16·2)/2 = 32/2 = 16 m² ziemi.
Zadanie 7. Przeciwprostokątna = a = 6√3 cm. Krótsza przyprostokątna = a/2 = 3√3 cm. Dłuższa przyprostokątna (wysokość trójkąta równobocznego) = h = (a·√3)/2 = (6√3 · √3)/2 = (6·3)/2 = 9 cm. P = (1/2)·(a/2)·h = (1/2)·3√3·9 = 27√3/2 cm² (≈ 23,36 cm²). L = a/2 + h + a = 3√3 + 9 + 6√3 = 9 + 9√3 = 9(1+√3) cm (≈ 24,57 cm).
Zadanie 8. h = (a·√3)/2 ⟹ a = 2h/√3 = 2 · 8√3/√3 = 16√3/√3 = 16 cm (przeciwprostokątna = bok trójkąta równobocznego). Krótsza przyprostokątna = a/2 = 8 cm. P = (1/2)·(a/2)·h = (1/2)·8·8√3 = 32√3 cm² (≈ 55,36 cm²). L = a/2 + h + a = 8 + 8√3 + 16 = 24 + 8√3 = 8(3+√3) cm (≈ 37,84 cm).
