Klucz odpowiedzi

Trójkąt równoboczny i równoramienny prostokątny — obwód, pole, wysokość (wariant D, poziom rozszerzony)

Wzory, które warto znać

Trójkąt równoboczny (bok a)
Obwód: L = 3a Wysokość: h = (a·√3) / 2 Pole: P = (a²·√3) / 4
Trójkąt równoramienny prostokątny (przyprostokątna a, przeciwprostokątna c)
Przeciwprostokątna: c = a√2 Obwód: L = 2a + a√2 Pole: P = a² / 2
Połówka trójkąta równobocznego (przyprostokątne a/2 i h, przeciwprostokątna a)
Pole: P = (a²·√3) / 8 Obwód: L = a·(3+√3) / 2 gdzie: h = (a·√3) / 2
gdzie a oznacza długość boku (w trójkącie prostokątnym — przyprostokątnej).
Przypomnienie przed rozwiązywaniem: √a · √b = √(a·b), w szczególności √a · √a = a  ·  wyłączanie czynnika przed pierwiastek, np. √48 = √(16·3) = 4√3  ·  (k√m)² = k²·m  ·  (p/q)² = p²/q²  ·  ułamek mnożymy przez liczbę, mnożąc licznik (mianownik zostaje bez zmian).
Zadanie 1. a = √48 = √(16·3) = 4√3 cm. L = 3a = 3 · 4√3 = 12√3 cm (≈ 20,76 cm).
Zadanie 2. h = (a·√3)/2 ⟹ a = 2h/√3 = 2 · 9√3 / √3 = 18√3/√3 = 18 cm. L = 3a = 3 · 18 = 54 cm.
Zadanie 3. P = (a²·√3)/4 = ((3/4)²·√3)/4 = (9/16 · √3)/4 = 9√3/64 dm² (≈ 0,24 dm²).
Zadanie 4. c = a√2 = 9√2 · √2 = 9 · 2 = 18 cm.
Zadanie 5. a = √98 = √(49·2) = 7√2 cm. P = a²/2 = (7√2)²/2 = (49·2)/2 = 98/2 = 49 cm².
Zadanie 6. a) L = 2a + a√2 = a(2+√2) = 6√2 · (2+√2) = 12√2 + 6·2 = 12√2 + 12 = (12√2 + 12) m ≈ 12·1,41 + 12 ≈ 28,92 m lamówki. b) P = a²/2 = (6√2)²/2 = (36·2)/2 = 72/2 = 36 m² materiału.
Zadanie 7. Przeciwprostokątna = a = 10√3 cm. Krótsza przyprostokątna = a/2 = 5√3 cm. Dłuższa przyprostokątna (wysokość trójkąta równobocznego) = h = (a·√3)/2 = (10√3 · √3)/2 = (10·3)/2 = 15 cm. P = (1/2)·(a/2)·h = (1/2)·5√3·15 = 75√3/2 cm² (≈ 64,88 cm²). L = a/2 + h + a = 5√3 + 15 + 10√3 = 15 + 15√3 = 15(1+√3) cm (≈ 40,95 cm).
Zadanie 8. h = (a·√3)/2 ⟹ a = 2h/√3 = 2 · 11√3/√3 = 22√3/√3 = 22 cm (przeciwprostokątna = bok trójkąta równobocznego). Krótsza przyprostokątna = a/2 = 11 cm. P = (1/2)·(a/2)·h = (1/2)·11·11√3 = 121√3/2 cm² (≈ 104,67 cm²). L = a/2 + h + a = 11 + 11√3 + 22 = 33 + 11√3 = 11(3+√3) cm (≈ 52,03 cm).
